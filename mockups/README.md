# Dev Containers Website Redesign Mockups

This directory contains 5 modern design mockups for the Development Containers website. Each mockup explores a different design direction to refresh the site's visual identity while maintaining its core purpose and content.

## Mockups Overview

### 1. Modern Minimal (`mockup-1-modern-minimal.html`)
**Design Philosophy:** Clean, spacious, and contemporary

**Key Features:**
- Large, bold typography with generous white space
- Minimal color palette (black, white, subtle grays)
- Smooth hover animations and transitions
- Card-based feature presentation
- Contemporary sans-serif typography
- Mobile-first responsive design

**Best For:** Organizations wanting a clean, professional look that emphasizes content over decoration.

---

### 2. Dark Mode First (`mockup-2-dark-mode.html`)
**Design Philosophy:** Contemporary dark theme with vibrant accents

**Key Features:**
- Dark background (#0a0a0a) with light text
- Gradient accents (purple/blue) for CTAs and highlights
- Glassmorphic navigation with backdrop blur
- Radial gradient hero background effect
- Syntax-highlighted code preview
- High contrast for readability

**Best For:** Developer-focused audiences who prefer dark interfaces and modern aesthetics.

---

### 3. Gradient Hero (`mockup-3-gradient-hero.html`)
**Design Philosophy:** Bold, colorful, and energetic

**Key Features:**
- Vibrant gradient backgrounds (purple, pink, blue)
- Animated dot pattern overlay
- Large, rounded cards with shadow effects
- Statistics section with gradient background
- Gradient text effects on headings
- High visual impact design

**Best For:** Projects wanting to stand out with bold, modern visuals and a youthful energy.

---

### 4. Split Screen (`mockup-4-split-screen.html`)
**Design Philosophy:** Asymmetric layout with strong visual hierarchy

**Key Features:**
- Full-height split hero section (50/50 layout)
- Code preview with syntax highlighting on right side
- Fixed navigation with shadow
- Blue accent color (#2b6cb0)
- Large circular feature icons
- Strong left-to-right reading flow

**Best For:** Sites wanting to showcase both messaging and code/product simultaneously.

---

### 5. Glassmorphism (`mockup-5-glassmorphism.html`)
**Design Philosophy:** Modern frosted glass effects with depth

**Key Features:**
- Frosted glass (glassmorphism) UI elements
- Gradient background with subtle pattern overlay
- Backdrop blur effects on all cards
- Semi-transparent white cards
- Soft shadows and layered depth
- iOS/modern app-inspired design

**Best For:** Projects wanting a cutting-edge, modern aesthetic with visual depth and sophistication.

---

## Viewing the Mockups

To view any mockup, simply open the HTML file in a web browser:

```bash
# From the repository root
open mockups/mockup-1-modern-minimal.html
# or
firefox mockups/mockup-2-dark-mode.html
```

Or navigate to the mockups directory and open the files directly in your browser.

## Design Considerations

All mockups maintain:
- ✅ Clear hierarchy and navigation
- ✅ Mobile-responsive design principles
- ✅ Accessibility considerations (contrast, font sizing)
- ✅ Fast loading (no external dependencies)
- ✅ Core messaging from the original site
- ✅ Modern web design standards

## Implementation Notes

These are static HTML mockups demonstrating visual design directions. To implement any of these designs in the actual Jekyll site, you would need to:

1. Update the CSS/SCSS files in the `css/` directory
2. Modify the layout templates in `_layouts/` and `_includes/`
3. Update color schemes in `_config.yml` (theme_color)
4. Test with the existing Jekyll build system
5. Ensure all existing pages work with the new design

## Recommendations

Based on the current Development Containers brand and audience:

- **Most Professional:** Mockup 1 (Modern Minimal)
- **Most Developer-Friendly:** Mockup 2 (Dark Mode First)
- **Most Eye-Catching:** Mockup 3 (Gradient Hero)
- **Best for Content Display:** Mockup 4 (Split Screen)
- **Most Modern/Trendy:** Mockup 5 (Glassmorphism)
